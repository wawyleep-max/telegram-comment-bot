# Telegram Comment Bot

Автоматическая отправка комментария под последний пост в выбранных Telegram-каналах через Playwright.

## Установка
pip install playwright
playwright install chromium


## Использование
1. Впиши свои каналы в CHANNELS и текст в TEXT
2. Запусти: python script.py
3. При первом запуске войди в Telegram по QR-коду

## Важно
Используй только на каналах, где это уместно (например, своих собственных).
Массовая рассылка одинакового текста нарушает правила Telegram и может привести к ограничению аккаунта.
